## 2. 保留的科学主线（TempoRAC 核心思想不变）

重复周期在视频间跨约 30 倍（RepCount-A 周期 0.2–6 s），且视频内节奏会漂移（周期变异系数中位 0.11、
90 分位 0.35，均来自官方 cycle 边界统计）。固定采样率编码器（16×4 帧 ≈ 2.1 s 窗）对快/慢重复都失配。

TempoRAC = 局部节奏证据 + 节奏专家软路由 + 一次解码：

- (A) **多速率 token 流**：同一冻结 ST-MAE ViT-B（与 ESCounts 相同编码器），帧步长 s∈{1,2,4}，
  75% 重叠滑窗，按原始帧网格对齐平均（`temporac_cvpr/extract_features.py`）。
- (B) **速率专家**：每个速率一个时序编码器，在各自网格上运行，固定感受野覆盖不同绝对周期。
- (C) **局部掩码 tempogram + 软路由**：逐格局部自相关（Hann 窗、掩码归一化、可 detach）
  → 每格单纯形权重混合专家响应 → 单一密度解码，计数 = 密度和。
- 训练目标：密度 MSE + 归一化计数 L1（两项）。RepNet 式基线额外需要周期监督（仅基线）。

监督口径如实披露：使用官方 cycle 边界生成密度目标（与 TransRAC/ESCounts 同类监督），不再宣称
"无计数标签"。

## 4. 比较方法

1. 已发表结果表（注明输入模态与监督）：RepNet、Context（Zhang 2020）、TransRAC、MFL、PoseRAC、
   ESCounts、CountLLM 等，数值逐一核对原文。
2. 同特征受控复现（同一冻结 token、同训练预算）：单速率 Transformer（ESCounts 无样例式解码器）、
   多速率拼接、TransRAC 式多尺度 TSM 头、RepNet 式周期头。
3. 官方实现/权重：ESCounts 官方解码器权重（E 盘已有 239 MB，待上传）在同一数据上评测；
   TransRAC/PoseRAC 权重待获取，拿不到如实标注。

## 5. 消融与分析

- 速率子集；路由 uniform / hard / soft / 无 tempogram；tempogram detach、滞后范围与窗宽；
  专家共享与否；密度 σ；损失权重；空间池化。
- 观察：误差随视频内节奏变异、周期区间的变化（基线 vs TempoRAC）。
- 机制：路由权重与 GT 局部周期的对应、熵。
- 节奏扰动压力测试：对测试视频做保计数的分段变速重采样后重抽特征。
- 效率：参数量、FLOPs、延迟（含/不含特征抽取）。
